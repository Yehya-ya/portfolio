Task Manager

A kanban REST API in Laravel and its native Android app.

Stack
Laravel 13, Sanctum, Pest, Java, Android
Links
API on GitHub Android app on GitHub

What it does

  • Projects with kanban columns. Every new project starts with To do, Doing and Done.
  • Tasks with a description, a due date and an assignee, moved from column to column.
  • Owners add members by email. Someone who hasn’t signed up yet is linked when they register.
  • Members see the whole board but can change only the tasks assigned to them.
  • Light and dark themes in the app.

How it’s built

  • API: a Laravel REST API with Sanctum tokens, form-request validation, a policy on every action and JSON resources. Sign-in and registration are rate limited.
  • Kept current from Laravel 8 in 2021 to Laravel 13 on PHP 8.5.
  • 51 Pest tests plus architecture tests, with a 98% coverage floor and 100% type coverage. Larastan and Rector keep it clean.
  • Android: Java with MVVM (ViewModels and LiveData), Volley for HTTP, and a board with one swipeable page per column.
