AI code review and releases

Claude Code skills that review and ship tickets across multiple repos.

Role
Project Lead, ISKAAN
Stack
Claude Code, MCP, Jira

Problem

One ticket can touch several repos. Preparing a release meant checking branches, pull requests and Jira by hand.

What I did

  • Review skill: finds every pull request for a ticket and checks it against the requirements.
  • Deploy skill: gathers ready tickets, resolves conflicts, opens the pull requests and writes the release sheet.
  • Guardrails: no force-pushes, never touches anyone’s working copy.

Result

Release prep is one command, and every ticket gets the same review before it ships.
