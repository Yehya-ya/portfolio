A new platform, from scratch

A Laravel API and two Angular apps, synced with an existing system.

Problem

A new product needed its own API and apps, while its users and core data stayed in an existing platform.

What I did

  • Designed and built the Laravel API.
  • Built two Angular apps: an admin panel and a user-facing app.
  • Synced users from the existing platform, so the data lives in one place.

Result

The product shipped on its own stack, with no duplicated user data.
